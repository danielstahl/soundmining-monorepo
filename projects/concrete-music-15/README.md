# Birds before the storm

## Description
This is the fifteens in a series of Concrete Music pieces. Composed 2026.
It uses granular-synthesis and generative techniques. The sound is a human "h" sound.
The source-code can be found at github.com/danielstahl/soundmining-monorepo/tree/main/projects/concrete-music-15.
